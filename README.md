
项目名称：**健身房管理系统**

技术架构：**Spring Boot + Vue.js + MySQL**
# 项目简介
本系统是一个基于 B/S 架构的健身房综合管理平台，采用前后端分离开发模式，支持三种用户角色（**管理员、会员、员工**）协同工作。系统集成**AI智能教练**（知识库问答）、**智谱大模型健身计划自动生成**、**高德地图附近健身房导航**等创新功能，实现了传统健身房管理的智能化升级。
