# Gym-management-system
后端使用Spring Boot结合MyBatis-Plus来保证业务逻辑的高效处理以及数据的持久化，前端用Vue.js和Element UI来创建响应式的交互界面，统以健身房日常运营为基础，对人员档案管理、会员卡全生命周期控制、健身资源调度、基于ECharts的数据统计可视化等进行了全部的功能设计。在此基础上，系统又加入了智能化的能力，使用智谱AI GLM-4-Flash大语言模型，根据用户的BMI指数、健身目标和训练等级等多方面因素，自动生成个性化的周训练计划，并且接入高德地图API获取LBS位置服务，找到附近的门店，另外还有基于关键词匹配的AI教练智能问答系统和具有点赞、收藏、评论功能的心得分享社区，使平台更加具有互动性以及用户活跃度。
