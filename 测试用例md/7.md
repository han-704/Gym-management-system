**测试方法**  异常注入测试

    - 格式A（标准JSON）：直接返回纯JSON字符串，无任何包装
    - 格式B（Markdown JSON）：返回```json ... ```包裹的JSON内容
    - 格式C（普通Markdown）：返回``` ... ```包裹的内容（无json标识）
    - 格式D（含错误字段）：返回包含error键的非标准响应
2. 观察解析器对各种格式的处理能力
**测试数据**  
格式A示例：{"planName":"测试计划","weeklyPlan":[{"day":1,"isRestDay":false,"exercises":[{"timePeriod":"上午","projectName":"深蹲","duration":30}]}]}

**预期结果**  格式A/B/C：parseFitnessPlan()均能成功提取JSON核心内容，去除markdown标记后正常解析为List<Map>结构，day、isRestDay、exercises等字段完整映射；
格式D：解析器捕获异常后不会崩溃，返回包含error键和rawResponse原始内容的Map对象，供上层Controller识别并触发备用方案（generateDailyPlansFallback）
**实际结果**  四种格式均被正确处理：纯JSON/Markdown包裹均可解析，异常响应安全降级至备用规则生成

**测试目的**  验证API调用失败时的降级处理机制——备用规则自动接管
**前置条件**  配置无效API Key或断网环境模拟API不可达
**测试方法**  故障注入测试
**测试步骤**  1. 临时修改配置将glm.api-key设为无效值（或断开外网连接）；2. 执行完整的计划生成流程（填写合法参数并提交）；3. 观察系统行为：
    - 是否抛出未捕获异常导致500错误？
    - 是否自动切换至备用生成逻辑？
    - 备用生成的计划是否仍具备基本合理性？
**测试数据**  正常参数：shengao="165", tizhong="55", jianshenmubiao="塑形", jianshendengji="初级", meizhouxunliantian=3；API Key设为"invalid_key_xxx"
**预期结果**  1. GLMAIService.generateFitnessPlan()因认证失败返回错误JSON（含error字段）；2. FitnessPlanController.generateDailyPlansByAI()检测到error键，打印错误日志"AI计划解析错误: ..."；3. 自动调用generateDailyPlansFallback()进入备用流程；4. 备用规则根据健身目标筛选对应类型项目（塑形→瑜伽/普拉提/力量训练/拉伸），按等级设置训练参数（初级3组12次60秒休息），均匀分配训练日至一周内；5. 最终仍返回code=0的成功响应，前端正常展示生成的计划（标注来源为备用规则而非AI）；6. 不向用户暴露底层API错误的敏感信息
**实际结果**  API调用失败时系统自动降级至备用规则引擎，用户无感知地获得基于规则的健身计划，计划包含7天完整安排（3训练日+4休息日），参数符合初级塑形目标设定

### 关键技术实现对照

| 功能模块 | 实现位置 | 核心逻辑 |
|---------|---------|---------|
| AI调用入口 | GLMAIService.generateFitnessPlan() | HTTP POST → open.bigmodel.cn/api/paas/v4/chat/completions，model=glm-4-flash |
| 系统提示词 | buildSystemPrompt() | 强制JSON输出格式约束（planName+weeklyPlan[7天]结构），训练强度等级规则 |
| 参数校验（前端） | plan-generate.vue rules | 身高/体重required+pattern正则，目标/等级required change |
| BMI自动计算 | calculateBMI() | bmi = weight / (height/100)²，四档分类（偏瘦<18.5/正常<24/偏胖<28/≥肥胖） |
| AI响应解析 | parseFitnessPlan() | 剥离```json/```markdown包装 → JSONObject解析 → List<Map>结构化 |
| 备用规则引擎 | generateDailyPlansFallback() → generateDailyPlans() | 目标→项目类型映射 + 等级→参数映射 + 均匀分布训练日 |
| CSV导出 | exportExcel() | StringBuilder拼接CSV，含会员信息头+表头+数据行，UTF-8编码 |
| TXT导出 | exportTxt() | 三段式文本拼接（概览/周计划/注意事项），按星期分组换行 |
